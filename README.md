# Квантовые шахматы

Обычные шахматы, но на каждом ходе игрок выбирает **два варианта** следующего хода.
Один из них выполняется случайно (50/50) — мгновенный «коллапс» позиции.
Соперник видит оба варианта до разрешения.

Стек: Vite, React, TypeScript, chess.js, react-chessboard.

## Режимы

- 🪑 **Два игрока** — hot-seat за одним устройством.
- 🌐 **По сети** — P2P через WebRTC (PeerJS используется только для установки
  соединения через бесплатный публичный брокер, дальше трафик идёт напрямую
  между браузерами, без сервера). Хост создаёт комнату, выбирает свой цвет
  и делится ссылкой `?room=<код>`.

## Запуск

```sh
npm install
npm run dev
```

Сборка и проверка типов:

```sh
npm run build
```

Деплой на GitHub Pages — автоматически через `.github/workflows/deploy.yml`
при пуше в `main` (Settings → Pages → Source: GitHub Actions).

## Сервер сигналинга

По умолчанию клиент использует `wss://dilesoft.ru:9002/peerjs`
(свой сервер из папки `server/`). Если он недоступен — автоматический
фолбэк на публичный брокер PeerJS. Переопределить можно переменными
сборки (`VITE_PEER_*`, см. корневой `.env.example`) либо вручную
в Lobby («Сервер соединения», сохраняется в localStorage и имеет
приоритет). Пустой хост в Lobby сбрасывает выбор на встроенный дефолт.
